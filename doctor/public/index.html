AI Calling Agent Trigger & Feeder Architecture

📡 How the AI Calling Agent Consumes Doctor Prescriptions:

1. Trigger Source: Supabase Database Webhook OR GET /api/v1/telephony/pending-triggers

2. Inbound JSON Payload Structure:

{
  "prescription_id": "uuid-here",
  "doctor_name": "Dr. Suresh Sharma, MD",
  "patient": {
    "uhid": "ARV-2026-001",
    "name": "Ramesh Gowda",
    "phone_number": "+919880112345",
    "literacy_status": "ILLITERATE",
    "preferred_language": "KANNADA",
    "device_type": "FEATURE_PHONE"
  },
  "medication_regimen": [
    {
      "medicine_name": "Metformin Hydrochloride",
      "dosage": "500mg",
      "no_of_days": 30,
      "frequency": "1-0-1 (Twice Daily)",
      "meal_relation": "After Food",
      "color_sticker": "RED",
      "symbol": "CIRCLE",
      "voice_prompt_hint": "Packet with RED Sticker (Morning / Red Circle)"
    }
  ]
}

🎙️ Voice Prompt Construction Rules:

  • For Low-Literacy Patients: Voice MUST refer to the physical color sticker and timing code (Red for Morning, Green for Afternoon, Blue for Evening) in patient's preferred language:
    "ನಮಸ್ಕಾರ ರಮೇಶ್ ಅವರೇ. ಕೆಂಪು ಬಣ್ಣದ (RED / ಬೆಳಗಿನ) ಸ್ಟಿಕ್ಕರ್ ಇರುವ ಮಾತ್ರೆ ತಗೊಳ್ಳಿ. ತೆಗೆದುಕೊಂಡಿದ್ದರೆ 1 ಒತ್ತಿ. ಸಹಾಯ ಬೇಕಿದ್ದರೆ 2 ಒತ್ತಿ."
  • Keypad DTMF Webhook Callback: Post result back to POST /api/v1/telephony/adherence-gather with digits:
    1 = Taken • 2 = Help Requested • 3 = Remind Later
  • SMS Dispatch: Concurrently dispatch neutral SMS token and appointment confirmation.
